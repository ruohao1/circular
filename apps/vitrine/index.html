01 / HOW IT WORKS

From the first request
to the final review.

Circular keeps the task, the agent’s work, and the proposed changes connected. You can follow the whole process in one place.

  1. 01

    Give the work a starting point.

    Choose a repository and describe the outcome, or bring in an issue from Linear. Select an agent with the instructions and model that fit the task.

    TASK + CONTEXT + AGENT
  2. 02

    Follow the work as it happens.

    Each run gets its own workspace. Follow the agent’s output and timeline, inspect saved artifacts, and stop a run when it needs a different direction.

    ISOLATED WORKSPACE + VISIBLE PROGRESS
  3. 03

    Decide what moves forward.

    Review the captured diff, open a draft pull request, and ask a separate reviewer to examine the changes. The decision to merge stays with you.

    DIFF + DRAFT PR + REVIEW
