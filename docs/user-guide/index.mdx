Circular is a place to give coding agents work and follow their progress.
Choose a repository, describe what you need, then review the agent's answer and
proposed changes in the console.

## A few useful terms

| In Circular | What it means for you                                           |
| ----------- | --------------------------------------------------------------- |
| Project     | Your place to organize related repositories, agents, and tasks. |
| Repository  | The source code an agent will work with.                        |
| Agent       | A reusable helper with instructions and a chosen model.         |
| Task        | What you want the agent to do.                                  |
| Run         | One attempt to complete a task.                                 |

Creating a task or an agent does not start work. **Start Run** starts an attempt
and opens the page where you can follow it.

## Find your way around

Use **Setup** to manage projects, repositories, agents, and connections. Use
**Runs** to start tasks and review their results. Check the **Project** selector
when switching between different codebases.

Search these guides with **Ctrl+K** or **⌘K**. If something is missing or a run
needs attention, start with [Troubleshooting](/docs/troubleshooting).
